2.HTTP request y uni 3 mas`

1.request line - GET/users HTTP/1.1 (baxkacac e method, path, HTTP version ic)
2.headers - host/content-type/authorization (requesti masin texekutyunner stanalu metodner en)
3.body - {"name" : "Armen"} (ogtagorcvum e POST, PUT, PATCH i jamanak, aysinqn tvyalner poxelu hamar) 

3.HTTP response uni 3 mas`

1.status-line - HTTP/1.1/200 "OK" (cuyc e talis requesty hajoxutyamb exav te che)
2.headers - content-type/content-length (texekutyunner fayli masin)
3.body - {"message" : "success"}

5.HTTP methods`

1.GET - tvayl stanalu hamar GET/users
2.POST - nor data stexcelu hamar POST/users
3.PUT - amboxj objecty tarmacnum e PUT/users/1
4.PATCH - masamb e tarmacnum objecty PATCH/users/1
5.DELETE - jnjum e resourc y DELETE/users/1

6.Status code categories`

1.1xx - informational (100 - continue, 101 - switching protocols)
2.2xx - success (200 - OK, 201 - created)
3.3xx - redirection (301 - moved permanently, 302 - found)
4.4xx - client error (400 - bad request, 404 - not found)
5.5xx - server error (500 - internal server error, 503 - service unavailable)
